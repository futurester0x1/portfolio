# Ujjwal Basnet Portfolio

This is my personal portfolio site and blog, featuring a custom terminal-themed homepage and a modern, print-ready CV.

- **Live Site**: [futurester0x1.github.io/portfolio](https://futurester0x1.github.io/portfolio/)
- **Tech Stack**: Vanilla HTML, CSS, and JavaScript. Structured with SEO best practices and JSON-LD schema.

## Project Structure

- `index.html`: Terminal-themed homepage
- `cv.html`: Modern card-themed CV
- `/blog`: Articles and thoughts on procurement and supply chain
- `styles/global.css`: Centralized design system and variables
- `Ujjwal-Basnet-CV-public.pdf`: Downloadable resume

## Features

- Persistent terminal theme with typing animation
- Modern, accessible CV with inline PDF preview
- SEO optimized with Open Graph tags and JSON-LD
- Print-friendly styles for the CV page
- Responsive design across all pages
